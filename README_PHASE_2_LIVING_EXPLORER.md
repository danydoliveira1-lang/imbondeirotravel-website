# Project Baobab — Phase 2: Living Explorer

This production package refines the Living Explorer into the editorial experience approved for Imbondeiro Travel.

## Included
- Accurate Angola map with Cabinda
- Premium antique-gold border and deep-green terrain treatment
- Interactive destination filters and markers
- Zoom, pan and reset controls
- Animated personal routes after two or more Angola destinations are saved
- Unified My Journey builder
- Beautiful editorial destination reveal panel
- Responsive desktop, tablet and mobile layouts
- Reduced-motion accessibility support
- Public npm registry configuration for Vercel

## Deployment
Upload the contents of this folder to the GitHub repository root. Keep middleware.js removed/disabled.

The ZIP intentionally does not include package-lock.json. Vercel will install from the public npm registry defined in `.npmrc`.
