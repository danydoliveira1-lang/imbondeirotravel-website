## One unified My Journey system
The following now feed the same saved journey:
- Living Explorer destinations
- Signature Angola Journeys
- World Collection destinations

Selections persist in the browser. Map route lines represent only the selected Angola locations that have geographic coordinates. Signature tours and worldwide destinations appear in the My Journey panel without creating artificial map routes.

`Craft My Journey` transfers the complete selection to the enquiry form.
