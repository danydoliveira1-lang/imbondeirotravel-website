# Project Baobab — Phase 2.2 Curated Discovery

This refinement keeps the public homepage calm and cinematic.

## Always visible in the main journey
- Logo
- Meet Angola
- The Imbondeiro Explorer
- My Journey
- Discover / Menu
- Signature Angola Journeys
- Contact

## Hidden until selected from the full-screen menu
- Beyond Angola
- Services
- Imbondeiro Journal
- DMC & Partners
- The People Behind the Journey

Selecting one of these chapters from the full-screen menu reveals only that chapter and scrolls to it. A discreet “Return to the main journey” control hides the chapter again and returns the visitor to the Explorer.

The same behaviour is used on desktop and mobile.
