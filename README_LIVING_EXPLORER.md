## Functional interactions
- Six working category filters
- Clickable destination cards
- Clickable glowing markers on the Angola map
- Animated route lines between category destinations
- Destination story panel with image, duration, highlights and Journey Note
- Add/remove destinations from My Journey
- Journey persisted in the browser with localStorage
- “Your Journey Is Taking Shape” after three selections
- Craft My Journey transfers selected destinations to the enquiry form
- Map zoom in, zoom out and reset controls
- Responsive desktop, tablet and mobile layouts

## Deployment
Upload the contents of this folder to the root of the GitHub repository. Do not upload the containing folder itself. Vercel should detect the Next.js project and redeploy automatically.
