# Project Baobab — Stable Hero + Luxury Living Explorer

## Hero
- Uses only the three local MP4 files in `public/videos/`.
- No remote Pexels stream and no YouTube iframe.
- One video is loaded at a time.
- A short opacity transition occurs before the source changes, reducing freezing.

## Living Explorer
- Accurate Angola and Cabinda SVG outline.
- Luxury dark-green terrain treatment with antique-gold borders.
- Clickable glowing map markers.
- Category filters update destinations and routes.
- Destination cards select a location; `+` adds it to My Journey.
- Map markers open the matching destination story.
- Zoom, pan and reset controls.
- Saved journey persists in localStorage.
- Craft My Journey transfers the selected route to the enquiry form.
- Responsive layouts for desktop, tablet and mobile.

## Upload
Upload the contents of this ZIP to the repository root. Keep `middleware.js` deleted/disabled.
